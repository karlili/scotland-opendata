# Scotland Open Data Hub

One REST API and one MCP server over Scottish public sector open data. The hub
harvests upstream catalogues into a local SQLite database, so search and
lookups are fast, and proxies row-level queries live to the upstream APIs.

## Sources

| id | Portal | Upstream API | What the hub does with it |
| --- | --- | --- | --- |
| `data-gov-scot` | [data.gov.scot](https://data.gov.scot/data) | CKAN Action API at `https://api.data.gov.scot/api/3/action/` | Harvests `package_search`; proxies `datastore_search` for datastore-backed resources |
| `statistics-gov-scot` | [statistics.gov.scot](https://statistics.gov.scot) | SPARQL 1.1 at `https://statistics.gov.scot/sparql` | Harvests every `qb:DataSet`; serves observations as rows; passes read-only SPARQL through |

Base URLs can be overridden with `DATA_GOV_SCOT_CKAN_URL` and
`STATISTICS_GOV_SCOT_SPARQL_URL`. New CKAN or SPARQL portals (councils,
agencies) are one entry in `src/sources/registry.ts`.

### How resources are classified

Every resource is stored with an `access_type`:

- `api`: a live endpoint. CKAN datastore resources and SPARQL data cubes are also `queryable`, meaning `/v1/resources/{id}/rows` proxies them.
- `csv`: a CSV download only.
- `file`: any other download.

Datasets with no `api` resource are still tracked, but `/v1/datasets` and the
`search_datasets` tool hide them unless asked (`has_api=any`, `include_csv_only`).

## Running

```sh
pnpm install
pnpm sync            # harvest every source into data/catalogue.db (or: pnpm sync data-gov-scot)
pnpm dev             # http://localhost:8787
```

- API docs: `/docs` (Scalar), spec at `/openapi.json` (generated by hono-openapi)
- MCP (Streamable HTTP): `/mcp`
- MCP (stdio, for Claude Desktop and similar): `pnpm mcp`

| Env var | Default | |
| --- | --- | --- |
| `PORT` | `8787` | |
| `CATALOGUE_DB` | `data/catalogue.db` | SQLite file |
| `ADMIN_TOKEN` | unset | Enables `POST /v1/admin/sync` with `Authorization: Bearer …` |
| `UPSTREAM_TIMEOUT_MS` | `30000` | |

## REST API

| Method | Path | |
| --- | --- | --- |
| GET | `/v1/sources` | Upstream portals, counts, last sync |
| GET | `/v1/datasets?q=&source=&has_api=true\|false\|any` | Full-text search (SQLite FTS5) |
| GET | `/v1/datasets/{id}` | Dataset with its resources |
| GET | `/v1/resources?access=api\|csv\|file&format=&dataset=` | Every tracked endpoint and download |
| GET | `/v1/resources/{id}/rows?limit=&offset=&q=&filters=&sort=` | Live rows from the upstream API |
| POST | `/v1/sources/{id}/sparql` | Read-only SPARQL passthrough |
| POST | `/v1/admin/sync` | Re-harvest (token required) |

IDs are `<source>:<upstream id>`, e.g. `data-gov-scot:population-estimates`.

## MCP tools

`list_sources`, `search_datasets`, `get_dataset`, `query_resource`, `run_sparql`.

## Development

```sh
pnpm typecheck
pnpm test
```

Tests run against hand-written CKAN and SPARQL responses, so they need no network.
