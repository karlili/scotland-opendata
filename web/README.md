# Scotland Open Data web

A TanStack Start (React) site for browsing the hub's catalogue and viewing the
data. It talks only to the hub's REST API.

| Page | What it shows | Hub endpoints |
| --- | --- | --- |
| `/` | Search box, catalogue totals, national portals, councils with harvested data | `/v1/sources`, `/v1/councils`, `/v1/datasets` |
| `/datasets` | Search with access (API / all / downloads only) and source filters, paged | `/v1/datasets` |
| `/datasets/:id` | Metadata, every resource with its access type, and a 10-row preview of the first queryable resource | `/v1/datasets/{id}`, `/v1/resources/{id}/rows` |
| `/resources/:id` | Live rows, paged; search and column sort for CKAN datastore resources; save the page as CSV; link to the same query as JSON | `/v1/resources/{id}`, `/v1/resources/{id}/rows` |
| `/sources` | Every harvested portal, its API kind, counts and last harvest | `/v1/sources` |
| `/councils`, `/councils/:id` | The 32-council register, filterable by provision, with each council's harvested datasets and feeds | `/v1/councils` |

All hub calls go through server functions (`src/lib/hub.ts`), so the browser
never calls the hub directly and the hub needs no public CORS setup.

## Running

Start the hub first (from the repo root: `pnpm sync && pnpm dev`), then:

```sh
cd web
pnpm install
pnpm dev             # http://localhost:3000
```

Production: `pnpm build && pnpm start`.

| Env var | Default | |
| --- | --- | --- |
| `HUB_URL` | `http://localhost:8787` | Where the web server reaches the hub |
| `HUB_PUBLIC_URL` | `HUB_URL` | The hub URL browsers use for the API docs and raw JSON links |

## API types

`src/lib/hub-api.d.ts` is generated from the hub's OpenAPI spec. After changing
the hub's routes or schemas, run the hub and regenerate:

```sh
pnpm gen:api         # reads $HUB_URL/openapi.json
pnpm typecheck
```

`src/routeTree.gen.ts` is generated by the TanStack Router plugin whenever
`pnpm dev` or `pnpm build` runs.
